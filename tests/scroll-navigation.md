# 分类切换滚动验收

## 用户操作剧本

1. 从站点首页进入，等待左侧频道与发布者、右侧新闻卡片出现。
2. 在新闻列表向下滚动至少一屏，点击左侧“游戏”，再分别测试“商业”“科学”“头条新闻”“最大来源”。每次点击前重新向下滚动。
3. 页面应立即回到顶部，对应入口高亮，第一张新闻卡片从顶部可见；浏览器 `window.scrollY` 应为 `0`。
4. 再向下滚动，点击“新闻”分组中的一个发布者，确认只显示该发布者新闻，页面回到顶部。换另一个发布者重复测试。
5. 向下滚动后点击“联合早报”，确认“联合早报 / 最新”标题与头图可见，`window.scrollY` 为 `0`。
6. 阅读中展开或折叠左侧发布者分组，确认新闻列表不跳回顶部。
7. 若入口没有内容，应在顶部看到“当前分类没有新闻”，可切换其他频道继续阅读；若网络加载失败，可用右下角刷新重试。
