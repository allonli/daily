# 静态新闻首页验收

这份剧本验证首次阅读、已有功能、刷新失败恢复和云端后台更新。单元测试不能替代浏览器实际操作。记录测试日期、地址、浏览器、生成时间、数据请求和截图；每项执行后再填写通过或失败。

## 准备

1. 运行 `npm test` 和 `npm run build`，再运行 `npm run preview`，按终端地址打开本次构建。
2. 本地 preview 只用于验证静态正文和交互，不能验证 Vercel ISR 或图片代理。生产地址为 https://allonli.vercel.app/。
3. 在新浏览器上下文中测试首次进入，保证没有站点 localStorage 或历史新闻缓存；打开网络面板记录请求。

## 首次进入与阅读

1. 从地址栏直接打开首页。用户应立即看到“联合早报 / 最新”、新闻标题、文章链接和右下角“更新于”时间，不应先出现“正在加载新闻”的空白列表。
2. 检查首个 HTML 响应，确认 `#app` 中已有新闻正文，并含 `#news-snapshot` JSON。首次页面初始化不请求 Brave feed、sources 或 `/api/zaobao`；JS、CSS、文章图片和必要的图片代理请求是允许的。
   头图预取成功时，其 `img.src` 为受支持的图片 data URI，首屏无需再请求该远程图片；预取失败或图片过大时允许回退原图片地址。
3. 点击一条新闻的标题或图片，确认打开正确文章的新标签页。关闭文章标签页后仍能回到原来的阅读页面。
4. 禁用 JavaScript，再用新页面打开首页。标题、正文列表、更新于时间及文章链接仍可见、可用；恢复 JavaScript 并重新打开页面后继续交互验证。
5. 若图片加载失败，正文和文章链接仍可阅读；若整个网站暂时不可达，恢复网络后重开首页。已有页面的刷新失败恢复见下文。

## 频道、来源及偏好

1. 从首页点击商业、游戏、科学、头条新闻和最大来源，再展开发布者分组并选择一个来源。每次都应显示相应列表；网络面板不新增新闻数据请求。
2. 从列表中段切换频道、发布者或联合早报，确认立即回顶且入口高亮；展开或折叠分组不打断阅读。完整回归步骤见 `tests/scroll-navigation.md`。
3. 点击右下角自定义按钮，查看来源卡片和正在关注数量。关注或取消一个来源，确认界面反馈并保存本地偏好；关闭弹层后继续阅读。
4. 重开页面，确认关注覆盖与折叠状态保留。无当前新闻的来源仍可在来源定制中出现，因为来源池完整保留。
5. 若某个筛选没有内容，应显示“当前分类没有新闻”；切换联合早报或其他频道恢复阅读。需要重新测试初始偏好时清除当前测试上下文的站点数据，再重开首页。

## 手动刷新及失败恢复

1. 记下当前新闻标题、频道、阅读位置和“更新于”时间，点击右下角 ↻。按钮检查期间暂时禁用，状态显示“正在检查更新…”，已有列表继续显示。
2. 检查网络面板，只新增本站 `/` 的 HTML 请求；不请求上游数据或 `/api/zaobao`。有新快照时显示新时间和数据；没有新快照时显示“已是最新一版”。
3. 在已打开的页面里阻断刷新请求或切换网络面板到离线，再点击 ↻。应显示“暂时无法更新，保留当前新闻；点击 ↻ 重试”，原列表、频道及阅读位置保留，按钮恢复可点击。
4. 恢复网络或移除阻断，再点击 ↻，确认可以继续更新或提示已是最新版本。不要在离线测试时关闭当前页面，否则测试的是首次网络连接而非刷新恢复。

## 生产静态缓存与后台更新

1. 部署后用新上下文打开生产首页，记录 HTML、内嵌 `generatedAt`、响应的 `x-vercel-cache` 和可用时的 `x-news-generated-at`。第一次尚无运行时缓存时也必须直接得到完整构建 fallback。
2. 随后再次请求相同首页，确认能看到缓存命中或后台更新完成后的完整页面，正文无需浏览器等待新闻接口。`MISS`、`HIT`、`STALE` 只说明缓存状态，还需比较生成时间。
3. 在 GitHub 仓库 Actions 中打开 **Refresh static news**，通过 **Run workflow** 手动运行，确认 curl 步骤成功。workflow 必须存在于默认分支。
4. 等待当前版本超过 240 秒并由调度或手动 workflow 请求首页。过期请求仍应立即返回旧正文；后台完成后再次请求，确认 `generatedAt` 增大，右下角“更新于”时间更新。
5. 查看后续计划运行记录，确认无人打开页面时仍有首页请求。当前计划约每 5 分钟，GitHub 可能延迟；一次 Actions 成功不等于后台新闻抓取成功。
6. 上游失败时，后台函数应报错并保留最后成功页面；用已有的抓取失败测试验证拒绝不完整快照，结合生产异常日志与持续可读的正文确认云端恢复。不要为了验收改坏生产数据源。
7. 若调度被停用，在 Actions 中重新启用并手动运行；若任务失败，检查运行日志、生产地址和网络。若请求成功但时间持续不变，检查 Vercel 后台函数日志及新闻上游，恢复后再次运行。旧版页面仍可阅读。
